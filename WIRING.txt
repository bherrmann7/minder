POWER SECTION (AC Mains → 5V DC)
--------------------------------

    AC HOT (Black/Brown) ──────┐
                               │
                         ┌─────┴─────┐
                         │  Hi-Link  │
                         │ HLK-PM01  │
                         │           │
                         │ AC    +Vo ├──────► 5V Rail
                         │ AC    -Vo ├──────► GND Rail
                         └─────┬─────┘
                               │
    AC NEUTRAL (White/Blue) ───┘


⚠️  WARNING: AC MAINS IS DANGEROUS!
    - Use proper strain relief on AC wires
    - Ensure enclosure is fully insulated
    - Double-check polarity before powering
    - The Hi-Link module is isolated but still be careful

ARCADE BUTTON WIRING (typical 5V illuminated button)
----------------------------------------------------

Each arcade button has 4 terminals:
  - 2 for the microswitch (NO = Normally Open, COM = Common)
  - 2 for the LED (+ and -)

AM BUTTON:
                    ┌─────────────────┐
                    │   AM BUTTON     │
                    │   ┌───────┐     │
                    │   │  LED  │     │
                    │   │  (+)──┼─────┼────► D5 (GPIO14)
                    │   │  (-)──┼─────┼────► GND
                    │   └───────┘     │
                    │                 │
                    │   SWITCH        │
                    │   (NO)──────────┼────► D1 (GPIO5)
                    │   (COM)─────────┼────► GND
                    └─────────────────┘

PM BUTTON:
                    ┌─────────────────┐
                    │   PM BUTTON     │
                    │   ┌───────┐     │
                    │   │  LED  │     │
                    │   │  (+)──┼─────┼────► D6 (GPIO12)
                    │   │  (-)──┼─────┼────► GND
                    │   └───────┘     │
                    │                 │
                    │   SWITCH        │
                    │   (NO)──────────┼────► D2 (GPIO4)
                    │   (COM)─────────┼────► GND
                    └─────────────────┘

GPIO SUMMARY TABLE
------------------

    Pin         GPIO    Function            Notes
    ───────────────────────────────────────────────────────────────
    D1          GPIO5   AM Button Switch    INPUT, internal pullup
    D2          GPIO4   PM Button Switch    INPUT, internal pullup
    D5          GPIO14  AM Button LED       OUTPUT
    D6          GPIO12  PM Button LED       OUTPUT
    5V          -       Power in            From Hi-Link +Vo
    GND         -       Ground              Common ground


NOTES ON BUTTON ACCENT COLORS
-----------------------------
Suggestion: Use different colored buttons or LED colors
  - AM: Yellow or White LED (morning sun)
  - PM: Blue or Orange LED (evening)

Or just use whatever you can get - function > form!
