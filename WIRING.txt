POWER
-----
USB cable from any 5V USB wall adapter to the Wemos D1 Mini's micro-USB port.
That's it.


ESP8266 WEMOS D1 MINI CONNECTIONS
---------------------------------

                        ┌───────────────┐
                        │  Wemos D1 Mini│
                        │               │
       USB 5V ─────────►│ 5V        3V3 │
       USB GND ────────►│ GND       GND │
                        │               │
       AM Button SW ───►│ D2 (GPIO4)    │
       PM Button SW ───►│ D1 (GPIO5)    │
                        │               │
       AM Button LED+ ─►│ D5 (GPIO14)   │
       PM Button LED+ ─►│ D6 (GPIO12)   │
                        │               │
                        └───────────────┘


ARCADE BUTTON WIRING (typical 5V illuminated button)
----------------------------------------------------

Each arcade button has 4 terminals:
  - 2 for the microswitch (NO = Normally Open, COM = Common)
  - 2 for the LED (+ and -)

AM BUTTON:
                    ┌─────────────────┐
                    │   AM BUTTON     │
                    │   ┌───────┐     │
                    │   │  LED  │     │
                    │   │  (+)──┼─────┼────► D5 (GPIO14)
                    │   │  (-)──┼─────┼────► GND
                    │   └───────┘     │
                    │                 │
                    │   SWITCH        │
                    │   (NO)──────────┼────► D2 (GPIO4)
                    │   (COM)─────────┼────► GND
                    └─────────────────┘

PM BUTTON:
                    ┌─────────────────┐
                    │   PM BUTTON     │
                    │   ┌───────┐     │
                    │   │  LED  │     │
                    │   │  (+)──┼─────┼────► D6 (GPIO12)
                    │   │  (-)──┼─────┼────► GND
                    │   └───────┘     │
                    │                 │
                    │   SWITCH        │
                    │   (NO)──────────┼────► D1 (GPIO5)
                    │   (COM)─────────┼────► GND
                    └─────────────────┘


GPIO SUMMARY TABLE
------------------

    Pin         GPIO    Function            Notes
    ───────────────────────────────────────────────────────────────
    D2          GPIO4   AM Button Switch    INPUT, internal pullup
    D1          GPIO5   PM Button Switch    INPUT, internal pullup
    D5          GPIO14  AM Button LED       OUTPUT
    D6          GPIO12  PM Button LED       OUTPUT
    5V          -       Power in            From USB
    GND         -       Ground              Common ground
